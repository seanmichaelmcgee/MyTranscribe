# MyTranscribe term set, English v1: classical medical terms in short fictional notes.
#
# Eponymous signs, tests, syndromes and diseases, organisms, classical descriptive terms,
# clinical scores and drugs a family physician dictates. Written 2026-11-20 for
# scripts/term_bench.py, which has synthetic voices read each item and then looks for every
# marked term in what each model writes. Every person and detail is invented.
#
# Format:
#   ## pronounce            then "term = how a clinician says it", a hint for the voice only
#   ## <id> | <topic> | <split>
#   one sentence per line; [[term]] marks a term to look for (written as it should appear)
# Split (tune or check) was fixed when the item was written, before any result was seen.
# [[a|b]]: a is written and said, and b is also accepted (cephalexin, cefalexin).
# Each marked term appears once in its item. Rules: tests/test_term_set.py.
